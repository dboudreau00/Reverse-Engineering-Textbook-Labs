esreveR Engineering for Beginners: lab programs, rebuilt 19 October 2026 from the sources printed in the book.

Toolchain (Ubuntu 24.04, the versions the book's appendix names): MinGW-w64 GCC 13.2 (msvcrt) for the C programs and DLLs,
UPX 4.2.2, osslsigncode 2.8, OpenSSL 3.0.13, Python 3.12 with pefile and NumPy for Lab 12.5, and the .NET SDK 8.0.131 for the four
C# labs. The C# labs target net8.0 and are built with dotnet build -c Release -r win-x64 --self-contained false, so each has a
Name.exe apphost, Name.dll and Name.runtimeconfig.json (framework-dependent; dotnet Name.dll runs it too).
Build commands are the ones in each lab.

Checked against the book: lab9_upx.exe is 8,192 bytes, with UPX0 49,152 bytes in memory and UPX1 entropy 7.53; lab1s.exe is 14,848 bytes
and its signature starts at 0x3A00; the 80-program dataset reproduces Lab 12.5's group table, the 75% entropy baseline, 100% on the
24 held-out samples and the weights +0.72, -2.89 and +2.89.
